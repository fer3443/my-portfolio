# AGENTS.md

Instrucciones para agentes de IA que trabajan en este repositorio. La guía técnica del proyecto (comandos, arquitectura, git workflow, verificación) está en `CLAUDE.md`.

## Memory

`MEMORY.md` (en la raíz del repo) es la memoria compartida entre sesiones.

- Al empezar, leé `MEMORY.md` para conocer el estado del proyecto y las decisiones tomadas.
- Al terminar una tarea, actualizalo: estado actual, decisiones importantes (con su porqué) y errores a evitar.
- Mantenelo breve (máximo ~50 líneas): resumí o eliminá lo que ya no aporte.
- Si algo se convierte en una regla permanente, proponé moverlo a `AGENTS.md` en lugar de dejarlo en la memoria.
- No guardes nunca datos sensibles (claves, tokens, datos personales).
